# 관리자 사용 가이드

SafetyPad Monitor(IoT 안전발판 위반 관제 대시보드)를 사용하는 **관리자**를 위한 화면별 안내서입니다.
서버 설치·백업·장애 대응은 `OPERATIONS_MANUAL.md`를 참고하세요.

> 이 가이드는 화면 문구와 동작을 코드에서 확인해 작성했습니다. 화면 캡처는 `docs/screenshots/`에 있습니다.

---

## 0. 빠른 시작 — 이럴 땐 이렇게

| 하고 싶은 일 | 방법 |
|---|---|
| **오늘 위반이 어디서 몇 건 났는지** 보고 싶다 | 대시보드 → "오늘 위반 건수" 카드 → 아래 **위반 위치 지도**. 또는 **위치·경로** → 기간 버튼 **오늘** |
| 지도의 **"위반 N건"이 무슨 뜻인지** 알고 싶다 | [5.2 지도 읽는 법](#52-지도-읽는-법) — 같은 지역에 모인 위반의 개수입니다. 마우스를 올리면 안에 어떤 장비가 몇 건인지 나옵니다 |
| **가장 위반이 많은 발판**을 찾고 싶다 | **위치·경로** → 오른쪽 **위반 목록**(위반이 많은 순) |
| 한 발판의 **위반 시각·위치를 하나씩** 확인하고 싶다 | 위반 목록에서 장비 선택 → 시각별 목록 → **지도에서 보기** |
| 경찰·지자체 **제출용 파일**을 만들고 싶다 | **위반 이벤트** → 기간·장비 필터 → **CSV 내보내기** ([3.3](#33-csv-내보내기)) |
| **새 발판을 등록**하고 연결하고 싶다 | **장비 관리** → 장비 등록 → API 키 발급 ([4.2~4.3](#42-장비-등록)) |
| 장비 데이터가 **안 들어오는** 것 같다 | [9. 문제 해결](#9-자주-묻는-질문--문제-해결) 첫 줄 |

## 1. 시작하기

### 1.1 접속과 로그인
1. 브라우저에서 배포된 주소(도메인)로 접속합니다. 로컬 개발 환경은 `http://localhost:5173`입니다.
2. **아이디**와 **비밀번호**를 입력해 로그인합니다.
3. 최초 관리자 계정은 서버 설치 시 `ADMIN_BOOTSTRAP_USERNAME / ADMIN_BOOTSTRAP_PASSWORD`로 만들어집니다(12자 이상). **내장 기본 계정은 없습니다.**
4. 첫 로그인 후에는 [운영 설정 → 내 비밀번호 변경](#8-운영-설정)으로 비밀번호를 바꾸는 것을 권장합니다.

| 상황 | 화면 메시지 / 동작 |
|---|---|
| 아이디/비밀번호 오류 | 오류 메시지 표시(어느 쪽이 틀렸는지는 알려주지 않음) |
| 로그인 시도가 너무 많음 | "로그인 시도가 너무 많습니다. 잠시 후 다시 시도해 주세요." (실패 횟수 기준, IP+아이디당 분당 10회) |
| 서버 연결 불가 | "서버에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요." |
| 일정 시간 미사용 | 세션 만료(서버 기준 30분). 다시 로그인 |

### 1.2 화면 구성
- **PC**: 왼쪽 진한 파란색 메뉴 + 오른쪽 본문. **모바일/태블릿**: 왼쪽 위 ☰ 버튼으로 메뉴를 엽니다.
- 메뉴: **대시보드 · 위반 이벤트 · 장비 관리 · 위치·경로 · 통계 리포트 · 운영 설정**
- 오른쪽 위의 로그아웃 버튼으로 종료합니다.
- 모든 시각은 **한국 표준시(Asia/Seoul)** 로 표시됩니다.
- **`가상 데이터`** 배지가 붙은 장비/이벤트는 시뮬레이션 데이터입니다. 실제 위반이 아닙니다.

### 1.3 꼭 알아둘 용어
| 용어 | 의미 |
|---|---|
| **발생 시각** | 안전발판이 다인탑승을 감지한 시각(기기 시계 기준). 증거 시각으로 사용됩니다 |
| **최초 수신 시각** | 서버가 해당 이벤트를 처음 받은 시각. 재전송되어도 **바뀌지 않습니다** |
| **지연** | 최초 수신 − 발생. 통신 음영 등으로 재전송이 늦으면 커집니다 |
| **시계 오차 의심** | 수신 시각이 발생 시각보다 60초 넘게 빠른 경우. 기기 시계(RTC) 오차 가능성 |
| **최근 수신** | 서버가 해당 장비에서 마지막으로 데이터를 받은 시각. **온라인/오프라인이 아닙니다** |

## 2. 대시보드 (홈)
한눈에 현황을 봅니다.

- **카드·차트·목록은 눌러서 자세히 볼 수 있습니다** (아래 "눌러서 확인하기" 표).
- **요약 카드**: 오늘 위반 건수(한국 시간 0시 기준), 누적 위반 이벤트, 등록 장비 수(활성 기준), 최근 24시간 수신 장비, 배터리 주의 장비
  - "최근 24시간 수신 장비"는 수신 기록 기준이며 온라인 수가 아닙니다.
  - 배터리 주의는 마지막 보고 배터리가 기준값(기본 20%) 이하인 장비입니다.
- **최근 7일 위반 추이**, **장비별 위반 상위(7일)** 차트
- 위반 기록이 없으면 "기간 내 위반 기록이 없습니다"가 표시됩니다.
- **최근 위반 이벤트** 목록: 행을 누르면 상세가 열립니다.
- **위반 위치 지도**: 위반이 발생한 지점만 보여 줍니다. 지도 위에 "위반 N건 · 장비 M대"와 범례가 표시됩니다. 처음에는 지도가 한 줄을 모두 차지하며 크게 표시됩니다. 마커를 누르면 지점 상세 카드가 지도에 고정되고, 그때에만 오른쪽에 **선택 장비** 패널이 나타납니다(모바일에서는 패널 위치로 자동 이동). **선택 해제**를 누르면 다시 큰 지도로 돌아갑니다. 읽는 법은 [5.2](#52-지도-읽는-법)를 참고하세요.

### 눌러서 확인하기
| 누르는 곳 | 이동하는 화면 |
|---|---|
| **등록 장비 수** 카드 | 장비 관리 (활성 장비만) |
| **오늘 위반 건수** 카드 | 위반 이벤트 — 오늘(한국 날짜) 이벤트. 카드 숫자와 목록 총 건수가 같습니다 |
| **최근 24시간 수신 장비** 카드 | 장비 관리 — 최근 24시간 안에 수신한 장비 (온라인 여부 아님). 위쪽의 필터 표시를 누르면 해제됩니다 |
| **배터리 주의 장비** 카드 | 장비 관리 — 마지막 보고 배터리가 기준값 이하인 활성 장비 |
| **7일 위반 추이**의 날짜 점 (키보드: Tab 후 Enter) | 위반 이벤트 — 그 날짜 |
| **장비별 위반 상위** 막대 | 위반 이벤트 — 그 장비의 최근 7일 |
| **지도 마커·묶음** | 장비 정보 패널 / 지점 상세 카드 ([5.2](#52-지도-읽는-법)) |
| 지도 제목 옆 **크게 보기·위반 목록** | 위치·경로 |
| **최근 위반 이벤트** 행 | 이벤트 상세 |
| 장비 정보 패널의 **이 장비의 이벤트 보기 / 장비 관리에서 보기** | 위반 이벤트 / 장비 관리 |

통계 리포트의 추이·상위 차트도 같은 방식으로 눌러서 볼 수 있습니다.

## 3. 위반 이벤트
경찰·지자체·공유 PM 업체 제출용 자료를 조회하고 내려받는 핵심 화면입니다.

### 3.1 검색·필터
| 조건 | 설명 |
|---|---|
| 기간 (한국 표준시) | 시작일~종료일. 한국 달력 기준 날짜 |
| 장비 ID | 예: `PAD-0001`. 입력 후 검색 |
| 수신 지연 | 전체 / 1분 이상 / 10분 이상 / 1시간 이상 — 통신 신뢰도 점검용 |
| GPS | 전체 / 위치 있음 / 위치 없음 |

- 조건에 맞는 결과가 없으면 "조건에 맞는 이벤트가 없습니다"가 표시됩니다. 기간이나 장비 ID를 넓혀 보세요.
- 하단에서 **이전/다음** 페이지로 이동하며, "총 N건 · 현재/전체 페이지"가 표시됩니다.

### 3.2 목록 보는 법
- PC: 표 형태(장비 ID, 발생 시각, 최초 수신, 지연, GPS 유무 등). 모바일: 카드 목록.
- 행/카드를 누르면 **이벤트 상세**가 열립니다.
  - 이벤트 ID, 장비 ID, 유형(다인 승차 `MULTI_RIDE`), **발생 시각(기기 기록)**, **최초 수신(서버 기록)**, 지연, 배터리, 위치
  - 시계 오차가 의심되면 경고 문구가 표시됩니다.
  - 위치가 있으면 **지도에서 보기**로 위치·경로 화면으로 이동합니다.

### 3.3 CSV 내보내기
1. 필요한 조건으로 필터를 설정합니다.
2. 오른쪽 위의 **CSV 내보내기**를 누릅니다.
3. 파일은 UTF-8(BOM)이라 **엑셀에서 한글이 깨지지 않습니다.** 시각은 한국 표준시입니다.

주의사항
- 한 번에 **최대 5만 행**입니다. 초과하면 일부만 내려가므로 기간을 나눠 받으세요(초과 시 서버가 잘림 표시를 보냅니다).
- 셀이 `=`, `+`, `-`, `@` 등으로 시작하면 엑셀 수식으로 실행되지 않도록 앞에 `'`가 붙습니다.
- **내보내기는 감사 로그에 기록**됩니다(누가·언제·어떤 조건).
- 제출 전에 `가상 데이터` 행이 섞여 있지 않은지 확인하세요(운영 환경에서는 가상 데이터가 없습니다).

## 4. 장비 관리
장비 등록, API 키 발급·폐기, 상태 확인을 합니다.

### 4.1 목록
- 장비 ID, 구역, 상태(사용/비활성), **최근 수신**, **배터리**, 마지막 위반 위치를 표시합니다.
- **장비 ID 검색**으로 찾고, **비활성 장비 숨기기** 체크로 비활성 장비를 목록에서 뺄 수 있습니다.
- 장비를 선택하면 **장비 상세**가 열립니다.

### 4.2 장비 등록
1. **장비 등록** 버튼 → 장비 ID(예: `PAD-0001`, 발판 QR ID와 동일하게), 별칭, 설치 구역 입력 → **등록**
2. 이미 있는 ID면 "이미 등록된 장비 ID입니다."가 표시됩니다.
3. 등록만으로는 장비가 데이터를 보낼 수 없습니다. 이어서 **API 키를 발급**하세요.

### 4.3 API 키 발급 (장비 상세 → API 키)
1. **새 키 발급** → **발급**
2. 키 원문이 **한 번만** 표시됩니다. **복사**해서 안전한 곳에 즉시 보관하세요. 닫으면 다시 볼 수 없습니다(분실 시 새 키를 발급).
3. 키를 펌웨어 업체/장비에 안전한 경로(메신저 평문 공유 금지)로 전달합니다.
4. 발급 기록은 감사 로그에 남고, 서버에는 키 원문이 아닌 해시만 저장됩니다.

### 4.4 키 교체 (무중단)
**새 키 발급 → 기기에 새 키 반영 → 이전 키 폐기** 순서로 진행합니다. 한 장비에 여러 활성 키가 동시에 있을 수 있어 교체 중에도 전송이 끊기지 않습니다.
- **폐기**한 키로는 더 이상 전송할 수 없습니다(401). 폐기 전에 기기에 새 키가 반영되었는지 확인하세요.
- 활성 키가 하나도 없으면 "활성 키가 없어 이 장비는 데이터를 보낼 수 없습니다."가 표시됩니다.
- 키 목록에서 발급/폐기 시각과 상태를 확인할 수 있습니다.

### 4.5 장비 비활성화/활성화
- **비활성화**하면 이 장비의 전송이 거부(403)됩니다. 분실·도난·고장 장비에 사용합니다. 기존 이벤트는 그대로 보존됩니다.
- **활성화**하면 다시 수신이 허용됩니다.

### 4.6 상태 해석
- **최근 수신**이 오래됐다고 해서 고장·오프라인으로 단정하지 마세요. 현재 규격에는 하트비트가 없고, 발판은 위반 때만 전송합니다.
- **배터리**는 마지막 보고값입니다. 배터리 필드는 선택이라 값이 없을 수 있습니다(정비 우선순위 참고용).

## 5. 위치·경로
기본 지도는 **위반이 발생한 지점**만 보여 줍니다. **장비의 실시간 위치가 아닙니다.**

### 5.1 화면 구성
| 영역 | 내용 |
|---|---|
| 위쪽 조건 | 시작일/종료일, **기간 빠른 선택**(오늘 · 최근 7일 · 최근 30일 · 전체 기간), 장비 ID 선택, 이동 경로 보기 |
| 가운데 **위반 위치 지도** | 범례 + 지도. 아래에 "표시 중: 위반 이벤트 N건 · 장비 M대" 요약 |
| 오른쪽 **선택 장비** | 최근 수신, 배터리, 누적 위반, 마지막 위반 위치 |
| 오른쪽 아래 **위반 목록** | 지도와 같은 데이터를 글자로 보여 줍니다(모바일에서는 지도 아래) |

> 화면 예시: `docs/screenshots/1440-map-list.png`(PC), `360-map-list.png`(모바일)

### 5.2 지도 읽는 법
| 표시 | 뜻 |
|---|---|
| 주황 마름모 | 위반 지점 1건 |
| 파란 알약 **"위반 N건"** | 서로 가까워 한데 묶인 위반 N건. 숫자는 **그 안의 위반 건수**이며 장비 수가 아닙니다 |
| 빨간 마름모(!) | 선택한 장비의 위반 지점 (다른 장비는 흐리게 표시) |
| 하늘색 선·점 / 점선 | 이동 경로 켠 경우에만: 정기 위치와 그 연결선 / 수집 간격이 큰 구간 |

- **묶음 위에 마우스를 올리면**(키보드는 Tab으로 이동) 지도 아래쪽에 카드가 나타납니다: **위반 건수 · 장비 수 · 기간 · 장비별 건수 상위 3대**.
- **묶음을 누르면** 확대되어 개별 위반 지점으로 풀립니다. (모바일: 한 번 눌러 확대)
- **마커를 누르면** 카드가 지도에 **고정**됩니다: 장비 ID, **위반 발생 시각**, **최초 수신 시각**, 위치. 카드의 **이 장비의 위반만 보기**로 해당 장비만 강조하고, **✕**로 닫습니다.
- 장비를 선택하면 지도가 **그 장비의 위반 지점에 맞춰** 확대됩니다. **선택 해제**를 누르면 전체 보기로 돌아갑니다.
- 키 없는 대체 지도에서는 방향키로 이동, `+` `−`로 확대·축소, ⟲ 버튼으로 전체 보기를 할 수 있습니다.

### 5.3 위반 목록으로 자세히 보기
1. **위반 목록**에는 장비별 위반 건수가 **많은 순**으로 나옵니다(막대 길이 = 건수, 최근 위반 시각 포함).
2. 장비를 누르면 지도가 그 장비로 맞춰지고, 목록이 **그 장비의 위반 시각별(최신순) 목록**으로 바뀝니다.
3. 항목의 **지도에서 보기**를 누르면 지도가 그 지점으로 이동하고 상세 카드가 고정됩니다(모바일은 지도로 자동 스크롤).
4. **전체 장비 목록**으로 돌아가거나, **이 장비의 이벤트 목록·CSV**로 이동해 파일로 내려받을 수 있습니다(현재 기간 조건이 유지됩니다).

### 5.4 기타 안내
- **GPS가 없는 이벤트**는 목록에는 남지만 지도에는 표시되지 않습니다(건수와 **목록에서 보기** 링크가 안내됩니다).
- 지도 최대 표시 건수를 넘으면 "일부만 보입니다"가 표시됩니다. 기간을 좁혀 보세요.
- 지도 제공자: 카카오맵 키가 설정되면 실제 지도, 아니면 **키 없는 대체 지도**(도로·건물 없음, 위치는 근사)가 표시됩니다.
  - "실제 지도를 불러오지 못해 대체 지도를 표시합니다"가 나오면 관리자(개발 담당)에게 지도 키/허용 도메인 설정을 요청하세요.

### 5.5 이동 경로 보기
1. **장비를 선택**하고(마커 또는 검색), **이동 경로 보기**를 켭니다. 전체 장비의 경로는 표시하지 않습니다.
2. 날짜를 선택하면 그날의 정기 GPS 수집 지점을 이은 선이 그려집니다.
3. 경로는 **기기가 위반과 별개로 주기적으로 보낸 GPS**로만 그립니다. 위반 지점끼리는 절대 연결하지 않습니다.
   - 수집 지점이 2개 미만이면 선을 그리지 않고 안내 문구를 표시합니다.
   - 간격이 큰 구간(기본 30분 초과)은 점선입니다. 실제 도로 경로가 아닙니다.
4. 이 기능이 꺼져 있으면 "이동 경로는 비활성화되어 있습니다…"가 표시됩니다. 현재 **운영 환경은 기본 꺼짐**이며, 기기의 주기 GPS 전송 규격이 승인된 후에 사용합니다.

## 7. 관리자 계정 관리 (운영 설정 → 관리자 계정)
- **관리자 목록**: 아이디, 상태, 마지막 로그인 시각
- **관리자 추가**: 아이디(영문·숫자·`.`·`_`·`-` 3~64자), 초기 비밀번호(12자 이상)를 입력해 **추가**. 초기 비밀번호는 안전한 경로로 전달하고 첫 로그인 후 변경하도록 안내하세요.
- **비활성화**: 즉시 로그인이 차단되고 **열려 있는 세션도 종료**됩니다. 퇴사자 처리에 사용하세요. 다시 **활성화**할 수 있습니다.
- **비밀번호 재설정**: 새 비밀번호(12자 이상)를 지정합니다.
- **내 비밀번호 변경**: 현재 비밀번호와 새 비밀번호(12자 이상) 입력. 현재 비밀번호가 틀리면 "현재 비밀번호가 올바르지 않습니다."
- 현재 모든 계정은 **동일한 관리자 권한**입니다(역할 분리 미확정). 계정 변경은 모두 감사 로그에 기록됩니다.

## 8. 운영 설정
서버 설정을 **읽기 전용**으로 보여 줍니다(여기서 바꿀 수 없음).

| 항목 | 의미 |
|---|---|
| 표시 시간대 | Asia/Seoul |
| 지도 제공자 | 카카오맵 / 키 없는 대체 지도 |
| MQTT 수신 | 꺼짐(REST만 사용) / 켜짐 — 열린 포트 표시(TLS, 개발 환경은 평문 포트). 기기 규격은 `MQTT_INTEGRATION.md` |
| 이동 경로 | 켜짐 / 꺼짐 |
| 주기 GPS 수신 (device-locations) | 꺼짐 — 펌웨어 규격 승인 전 |
| 데이터 보존·개인정보 | 보존 기간과 위치정보 처리 근거는 **아직 확정되지 않음.** 확정 전에는 원시 이벤트를 삭제·수정하지 않음 |

운영 설정 하단에는 **관리자 계정**(§7)이 있습니다.

### 개발 환경 전용 도구
`가상 데이터 도구 (개발 환경 전용)`는 개발/데모 서버에서만 나타나며 **운영 환경에는 존재하지 않습니다.**
- **가상 데이터 불러오기 / 초기화**: 가상 장비의 이벤트·위치만 대상. 실제 수신 데이터에는 영향이 없습니다.
- **데이터 랜덤 생성**(상단 버튼): 켜 두는 동안 가상 위반이 계속 생성되고 화면이 5초마다 갱신됩니다. 다시 누르면 멈춥니다. 생성분은 개별 삭제할 수 없고 초기화로만 지웁니다.

## 9. 자주 묻는 질문 / 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 장비가 이벤트를 보내도 목록에 안 보임 | ① 장비가 등록·활성 상태인지 ② 활성 API 키가 있는지 ③ 필터(기간·GPS·지연)가 좁지 않은지 ④ 장비의 오류 응답(401 키 오류, 403 키-장비 불일치/비활성, 422 값 오류) |
| 같은 이벤트가 두 번 보이는지 | 같은 장비·이벤트 ID의 재전송은 1건으로만 저장됩니다. 최초 수신 시각은 유지됩니다 |
| 지연이 큰 이벤트가 많음 | 통신 음영지역일 수 있습니다. "수신 지연" 필터로 대상 장비·지역을 확인하세요 |
| "시계 오차 의심" 표시 | 해당 장비의 시계(RTC) 점검 필요. 증거 제출 전에 담당자와 확인 |
| 지도에 점이 안 보임 | 해당 이벤트에 GPS가 없는 경우입니다. 목록에는 남아 있습니다 |
| 지도에 숫자만 보여서 내용을 모르겠음 | "위반 N건"은 묶인 위반 개수입니다. 마우스를 올리면 장비별 내역이 나오고, 오른쪽 **위반 목록**에서 장비·시각별로 확인할 수 있습니다 |
| 지도에서 원하는 날짜만 보고 싶음 | 위치·경로 위쪽 **오늘 / 최근 7일 / 최근 30일** 버튼 또는 시작일·종료일을 지정하세요 |
| CSV가 엑셀에서 깨짐 | 파일을 더블클릭해 열어 보세요(BOM 포함). 그래도 깨지면 "데이터 가져오기 → UTF-8" 사용 |
| 화면이 갑자기 로그인으로 돌아감 | 세션 만료(30분) 또는 계정이 비활성화됨 |
| "요청을 처리하지 못했습니다." | 잠시 후 재시도. 반복되면 `OPERATIONS_MANUAL.md`의 장애 대응 참고 |

## 10. 보안 수칙
- 비밀번호는 12자 이상, 다른 서비스와 겹치지 않게 사용하고 공유하지 마세요. 사람마다 계정을 따로 만드세요.
- API 키 원문은 발급 화면에서만 볼 수 있으며, 채팅·이메일 평문 전달을 피하세요.
- 공용 PC에서는 사용 후 반드시 로그아웃하세요.
- CSV에는 장비 ID·시각·위치가 포함됩니다. 제출 목적 외로 유통하지 마세요(내보내기는 감사 기록됨).
- 감사 대상 작업: 로그인/실패, CSV 내보내기, 장비 등록, 키 발급/폐기, 장비 활성 변경, 계정 추가·비활성화·비밀번호 변경.
