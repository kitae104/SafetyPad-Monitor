## 2. 점검 중 발견해 수정한 결함
| 결함 | 영향 | 수정·검증 |
|---|---|---|
| 잘못된 Content-Type·405 등 프레임워크 4xx가 **500**으로 응답 | 기기가 “서버 오류”로 오해해 영구 재시도 | 415 등으로 수정, 테스트 추가 |
| 로그인 쓰로틀이 성공 로그인까지 계산 | 정상 관리자가 잠길 수 있음 | **실패 횟수만** 계산 |
| 비활성화한 관리자의 **이미 열린 세션이 유지** | 퇴사자 계정 비활성화가 즉시 효력 없음 | 요청마다 활성 여부 재확인 필터 + 실패 우선 테스트 |
| 메트릭 엔드포인트 401이 403으로 덮임(`sendError`→`/error` 재진입) | Basic 인증 클라이언트 혼동 | 응답을 직접 작성 |
| 기본 프로파일이 `dev` | 운영에서 프로파일 지정을 잊으면 데모 도구가 켜짐 | 기본을 운영 안전으로 변경, dev는 명시 활성화 |
| 성공 카운터가 커밋 전에 증가 | 롤백된 이벤트가 “수락”으로 집계 | 커밋 후 집계 |
| 지도: 포인터 캡처가 마커 클릭을 가로챔 / 격자 클러스터가 단일 마커를 가림 / 360px 가로 스크롤 | 사용 불가 또는 오동작 | 수정, 불변식 단위 테스트·E2E |
| Caddy 설정 파싱 오류(빈 이메일), 헬스체크가 dash에서 실패 | 배포 시 기동 실패 | 수정, 스모크 29/29 |
| 복구 스크립트가 실패 시 임시 DB를 남김 | 지저분한 상태 | 자동 정리 |

## 3. 운영 환경에서 직접 확인한 항목 (로컬 운영 스택)
* 응답 헤더: HSTS, CSP, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Server` 숨김.
* CORS: 외부 Origin의 사전 요청에 `Access-Control-Allow-Origin` 없음. TLS 1.1 거부, 1.2 허용. HTTP→HTTPS 308 리디렉션.
* 공개 엣지가 `/actuator/prometheus`, 데모 경로, Swagger를 404로 차단. 메트릭은 내부망 Basic 인증에서만 200.
* 엣지 접근 로그에서 요청 헤더·응답 헤더 제거(Set-Cookie는 기본으로도 `REDACTED`). 백엔드 로그에 `spk_` 0건.
* 로그아웃 후 이전 세션 쿠키 401. 오류 본문에 스택·클래스명 없음.

## 4. 의존성
* 프런트 `npm audit`: 운영 번들 의존성(`--omit=dev`) **0건**. 전체 10건(중간 심각도)은 모두 개발 도구(eslint·minimatch DoS)이며 배포물에 포함되지 않음. 제안된 `--force` 수정은 eslint를 내리는 방향이라 **적용하지 않음**(수용).
* **백엔드(Gradle) 의존성 취약점 스캔은 수행하지 않았습니다**(오프라인 DB 없음). CI에서 OWASP Dependency-Check 또는 Dependabot 도입을 권장합니다.
* Spring Boot 4.1.2는 작성 시점의 4.1.x 최신 GA입니다. 패치 릴리스를 정기 반영하세요.
