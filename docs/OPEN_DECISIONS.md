# 결정이 필요한 항목 (한 번에 회신용)

개발은 아래 항목을 **기본값으로 가정하고 끝까지 진행**했습니다. 기본값을 그대로 쓰면 되는 항목은 “기본값 OK”만 답해 주세요.
“막히는 것”이 있는 항목은 결정이 없으면 해당 기능을 **켜거나 출시할 수 없습니다.**

회신 예시: `A-1 지원함 / A-2 승인서 첨부 / B-8 법무 확인 후 다시 / C-12 대체 지도 유지 / 나머지 기본값 OK`
